RELEASE: YouMadBro 1.0.0

[ Bot Engine & Automation ]
- Visual Bot Script Builder:
  * Kill Monster (Modes: Once, Count, Item Drop)
  * Join Map & precise Cell / Pad Jump
  * Auto Quest Accept & Complete (with item reward selector)
  * Wait Delay interval timer
  * Bank & Inventory item transfer
  * Custom Notification trigger command
- Uncapped Bot Repeat loop mode with runtime stats (live running timer, loop counter, step indicator)
- Leave Combat on Stop/Pause safety toggle to auto-disengage targets
- Item Drops Whitelist manager with auto-accept and local drop notification toggle
- Script save & load support via JSON (.json) format and SAF document picker

[ Background Process & System Integration (Android ANE) ]
- Persistent Foreground Keep-Alive Service with Partial WakeLock and WifiLock
- Uninterrupted bot execution during screen-off, device standby, or app minimized
- Battery optimization unrestricted exemption request
- Picture-in-Picture (PiP) floating game mini-window (with Android 12+ Auto-Enter support)
- Native System Notifications for bot completion, whitelist drops, and disconnect alerts
- Optimized notification channel priority without continuous vibration buzzing

[ Virtual Joystick & In-Game Utilities ]
- Floating virtual joystick with responsive angle calculation and stop-walk handling
- Drag-and-drop repositioning with Edit Layout mode (save/hide via Settings menu)
- Quick action menu: Quest Loader, Cell Jump, Lag Killer, Hide Players, Open Bank, Set Spawnpoint, Packet Logger
- Auto Battle toggle with class safety checks and anti counter-attack protection

[ Mobile UX & Chat Helper ]
- Floating Chat Preview bar at top-center to prevent mobile soft keyboards from obscuring chat input
- Real-time typed text mirror with blinking cursor, quick Clear button, and Send button

[ Account Manager ]
- Multi-account local storage with encryption
- 1-tap quick account switching and automatic login
- Password visibility toggle and grab-from-game credentials button
- SAF import & export for account rosters (accounts.json)

- Fixed item and quest reward preview asset loading (qRewardPrev allowCodeImport & binary loading)
