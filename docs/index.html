Installation & Setup

Android Installation (Recommended)

  1. Download the latest release APK (YouMadBro_armv8-1.1.0.apk) from the GitHub Releases Page.
  2. Install the APK on your device (enable "Install unknown apps" if prompted by Android).
  3. Storage Permission: When first opening the bot manager, allow storage access so scripts can be read from Documents/YouMadBro/Bots/.
  4. Battery Profile: In Android Settings > Apps > YouMadBro > Battery, select Unrestricted so Android will not suspend the process when screen turns off.
Tip Android 11+ All Files Access: On modern Android versions, grant All files access to YouMadBro in Settings to allow direct saving and loading from your public Documents/YouMadBro/Bots/ directory without requiring SAF picker dialogs every time.

macOS Desktop Run & Build

YouMadBro can run natively on macOS for desktop testing or high-performance farming:

Terminal (macOS) 
# 1. Clone repository
git clone https://github.com/Froztt13/you-mad-bro.git
cd you-mad-bro

# 2. Run immediately via ADL (Adobe AIR Debug Launcher)
./run_mac.command

# 3. Or package as a standalone macOS .app bundle
./build_mac.command

Bot Manager: Interface & Tab Reference

The Bot Manager (located in loader/src/input/bot_manager/) is designed with a high-efficiency two-column layout optimized for touchscreens and desktop screens alike:

  • Left Column (Column 1): Active command stack, execution telemetry, reordering controls, and playback buttons.
  • Right Column (Column 2): Six specialized tabs for adding commands, configuring conditionals, setting parameters, and managing script files.
Left Panel: Command Stack & Execution Controls
BotManagerUI.as

The left panel acts as the master control center for your automation. Every command in the active routine appears here in sequential order.

Command List Table
Scrollable view displaying step numbers, command types, and parameters. While the bot is running, the active command is highlighted with an emerald border and a live arrow indicator.
Insert Below Mode
Clicking any command highlights it as the active insertion target. Any new command added from any tab will be inserted immediately beneath the selected row instead of at the very bottom.
Inline Parameter Edit
Clicking a command opens BotEditCommandModal, allowing instant modification of monster names, delay seconds, map details, or quest IDs without needing to delete and recreate the step.
Telemetry & Loop Stats
Real-time dashboard displaying total command count (X Commands), running duration timer (hh:mm:ss), and iteration counter (Loop: X).
Playback Controls
Start (▶) begins execution from step 0 or selected row; Pause (⏸) freezes execution state; Stop (⏹) halts the engine and resets pointer.
Stack Reordering & Delete
Move Up (▲) and Move Down (▼) shift command positions in the sequence. Each row has a ✕ delete button, and Clear wipes the entire list after confirmation.

BotCombatTab.as

Configures monster targeting, hunting behaviors, and kill conditions.

Visible and default-checked when Hunt is enabled. Locks your character into the single room with the highest monster population to maximize farming speed without room-change lag.
Action Button: Add Combat Command
Generates a HuntCommand or KillCommand with all configured parameters and adds it to the left stack.

Smart Hunt & Cell Density Locking

The Hunt command is an intelligent evolution of the basic Kill command. Instead of waiting blindly in the current cell, it tracks monsters across the entire map.

Feature Standard Kill Smart Hunt (YouMadBro)
Cross-Cell Jumping No (Stays in current cell) Yes (Automatically jumps to cell where monster is alive)
Most-Monsters-Only N/A Yes (Identifies and camps the cell with highest monster count)
Target Matching Basic substring match Exact Name Match (Prevents locking on "Luxuria Guard" when hunting "Luxuria")
Auto Target Cancel No Yes (Cancels target immediately if locked onto an unintended mob)
Note Why Most-Monsters-Only is recommended: When farming monsters that spawn across multiple rooms (e.g. Dark Makai in /tercessuinotlim), jumping back and forth causes transition delays and lag. Enabling Most-Monsters-Only keeps your player anchored in the room with the most spawns, killing continuously with zero room transitions.

Control Flow & 14 Conditional Logics

YouMadBro provides 14 built-in condition checks in the Misc Tab. If the evaluated condition is met (true), execution proceeds to the next command. If the condition is false, the bot skips exactly 1 command immediately below.

Condition Type Variable 1 (Var 1) Variable 2 (Var 2) Evaluation Logic
isItemInInventory Item Name Quantity (Default: 1) True if player has at least Var 2 quantity of Var 1 in bag.
isItemNotInInventory Item Name Quantity (Default: 1) True if quantity of Var 1 in bag is less than Var 2.
isItemEquiped Item Name — True if Var 1 is currently equipped on player character.
isItemNotEquiped Item Name — True if Var 1 is not equipped on player character.
isQuestAvailable Quest ID — True if quest ID is loaded and available to accept.
isQuestNotAvailable Quest ID — True if quest ID is locked or unavailable.
isQuestCanBeTurnedIn Quest ID — True if all quest requirements are satisfied and ready for turn-in.
isGoldGreaterThan Amount — True if player gold balance is greater than the specified amount.
isGoldLessThan Amount — True if player gold balance is less than the specified amount.
isMap Map Name — True if player is currently in the specified map.
isMapNot Map Name — True if player is not in the specified map.
isCell Cell Name — True if player is currently residing in the specified cell.
isCellNot Cell Name — True if player is not in the specified cell.
isPlayerMember — — True if player account has an active Membership upgrade.

Bot File Explorer & Subfolder Navigation

Unlike legacy clients that dump all scripts into one flat list, YouMadBro includes a full nested file explorer built into both the Load Bot and Save Bot modals.

Key Explorer Capabilities

  • Nested Subdirectories: Create and browse folders like Bots/Nulgath/, Bots/Forge/, or Bots/Dailies/.
  • Real-Time Breadcrumbs: Header subtitle updates dynamically showing your current path.
  • Safe Boundary Protection: Navigation up (.. Back/Up) stops strictly at your bot root folder, preventing accidental escapes.
  • 1-Tap Replace (Overwrite): In the Save dialog, clicking any existing file in the list automatically fills the input name and highlights the row. The button dynamically switches to Replace with an amber overwrite warning.
  • SAF Native Fallback: Android Storage Access Framework button allows importing/exporting from Downloads, Cloud Drives, or SD cards.

Background Execution & Android Optimization

Android aggressively terminates background apps to save battery. YouMadBro includes a native Java ANE (Air Native Extension) called BatteryOptimizer that keeps the connection alive.

Three-Pillar Background System

  1. Foreground Service: Displays a persistent notification showing bot status, preventing Android LMK (Low Memory Killer) from evicting the process.
  2. Partial WakeLock & WifiLock: Keeps the CPU running and WiFi chip awake even when the screen turns off.
  3. Picture-in-Picture (PiP): Tap the PiP button in Bot Manager to float a compact live preview window on top of other apps (Auto-enters PiP on Android 12+).
Warning Disable OEM Battery Killers: Device manufacturers like Xiaomi (MIUI/HyperOS), Huawei, and Samsung have custom task killers. Set YouMadBro battery profile to "No restrictions" and lock the app card in your Recent Apps screen for maximum stability.

Memory & Performance Optimization

Long botting sessions across multiple maps can lead to memory bloat and FPS drops. Version 1.1.0 implements aggressive map transition memory cleanup:

  • Map Cleanup Routine: Calls cleanupMap upon leaving rooms to cleanly unhook animations, sound clips, and timers.
  • ApplicationDomain Isolation: Each map SWF loads into an isolated child domain, allowing the ActionScript 3 garbage collector to immediately reclaim unused assets.
  • CPU Render Mode: Native CPU rasterization is verified in app.xml to eliminate GPU texture upload stalls on mobile chipsets.

FAQ & Troubleshooting

Bot stops when screen turns off?

Go to Android Settings > Apps > YouMadBro > Battery > Set to Unrestricted. Also verify that you haven't enabled battery saver mode.

No bot files (.json) appear in Bot Load Modal?

Make sure your bot JSON files are located in Documents/YouMadBro/Bots/. Alternatively, click Import File (SAF) in the Load Modal to pick the file directly from Downloads or Google Drive.

Game FPS drops in crowded maps?

Use the in-game quick menu to toggle Hide Players and Lag Killer. This turns off high-polygon cape, helm, and pet animations from other players.
